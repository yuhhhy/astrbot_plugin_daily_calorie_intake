# 每日热量助手

一个使用 AstrBot 当前聊天模型的多模态能力分析食物图片、通过对话记录文字饮食、自动记录每日摄入并计算剩余热量的插件。

## 使用要求

- AstrBot 4.9.2 或更高的 4.x 版本。
- 当前会话必须配置支持图片输入的多模态聊天模型；纯文字记录使用当前聊天模型即可。
- 识别结果只是估算，不替代医生或营养师建议。

## 使用方法

1. 发送 `/热量 开始`，依次填写年龄、身高、体重、生理性别、活动水平和目标。
2. 发送食物图片，或直接用文字描述饮食，插件会调用当前会话的多模态模型进行分析并自动入账，同时估算蛋白质/碳水/脂肪。
3. 忘记当天记录也没关系：说“我昨天晚上吃了火锅，帮我记一下”即可补记到昨天（最多补记最近 7 天）。

## 指令

- `/热量 开始`：首次创建个人档案。
- `/热量 配置`：进入配置对话，按提示修改年龄、身高、体重、性别、活动或目标；每次修改后自动重算 TDEE 和目标，回复“完成”退出。
- `/热量 今日`：查看今日摄入、剩余额度、宏量营养素小计和带编号的明细。
- `/热量 查询 [日期]`：查询指定日期的明细，支持 `昨天`、`前天` 或 `YYYY-MM-DD`，缺省为今天。
- `/热量 周报`：查看最近 7 天的摄入统计——日均值、达标天数、最高的一天、摄入趋势和逐日明细。
- `/热量 订阅 开启 [HH:MM]`：订阅每日饮食总结（默认 21:00 推送）；每周检查近 7 天累计缺口/超标，必要时提醒更新体重。
- `/热量 订阅 关闭` / `/热量 订阅 状态`：退订 / 查看订阅情况。
- `/热量 撤销 [日期]`：列出指定日期（缺省今天，支持 `昨天`、`前天` 或 `YYYY-MM-DD`）的记录，在后续对话中选择要撤销的一笔。
- `/热量 清空`：二次确认后清空个人档案与全部饮食记录，删除后无法恢复。
- `/热量 导出`：把全部饮食记录导出为 CSV 文件发送；需平台支持文件发送（OneBot/NapCat 等，QQ 官方平台仅群聊可用）。
- `/自动记录 开启`：开启整个插件的新增热量记录。
- `/自动记录 关闭`：暂停整个插件的新增热量记录。
- `/自动记录 状态`：查看当前设置。

## 隐私与存储

插件只保存用户档案、热量估算和消息 ID，不保存食物图片。数据使用 AstrBot 的插件 KV 存储，并按平台实例和发送者隔离。
